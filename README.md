# หลักสูตร PostgreSQL ฉบับสมบูรณ์
### เขียนและพัฒนาโปรแกรม/เว็บแอปพลิเคชันด้วย PostgreSQL — จากศูนย์สู่ระดับมืออาชีพและระดับโลก

หลักสูตรนี้พาผู้เรียนเดินทางแบบ **step-by-step ตั้งแต่ขั้นตอนที่ 1 ถึง 1000** ผ่านเนื้อหากว่า **100 ส่วน (Part)** โดยแต่ละ Part สามารถนำไปใช้งานได้จริง 100% พร้อมตัวอย่างโค้ด SQL, แบบฝึกหัด, และโปรเจกต์จริงประกอบทุกช่วง

## โครงสร้างหลักสูตร

| ระดับ | Steps | Parts | โฟลเดอร์ |
|---|---|---|---|
| 🟢 พื้นฐาน (Foundations) | 1–200 | Part 01–20 | [`course/01-foundations`](course/01-foundations) |
| 🔵 ระดับกลาง (Intermediate) | 201–400 | Part 21–40 | [`course/02-intermediate`](course/02-intermediate) |
| 🟣 ระดับสูง (Advanced) | 401–600 | Part 41–60 | [`course/03-advanced`](course/03-advanced) |
| 🟠 ระดับมืออาชีพ (Professional) | 601–800 | Part 61–80 | [`course/04-professional`](course/04-professional) |
| 🔴 ระดับโลก/ผู้เชี่ยวชาญ (World-Class) | 801–1000+ | Part 81–104 | [`course/05-world-class`](course/05-world-class) |

ดูสารบัญฉบับเต็มพร้อมรายละเอียดทุก Part ได้ที่ **[course/00-ROADMAP.md](course/00-ROADMAP.md)**

## วิธีใช้หลักสูตรนี้

1. เริ่มจาก `course/01-foundations/part-001-*.md` แล้วไล่เรียงตามลำดับเลข Part
2. ทำแบบฝึกหัดท้ายบทและโปรเจกต์รวมท้ายแต่ละระดับก่อนขึ้นระดับถัดไป
3. ทุกตัวอย่าง SQL รันได้จริงกับ PostgreSQL 16/17 — แนะนำให้เปิด `psql` หรือ Docker container ควบคู่ไปกับการอ่าน
4. โค้ดตัวอย่างและ dataset สำหรับฝึกอยู่ใน [`course/datasets`](course/datasets)
